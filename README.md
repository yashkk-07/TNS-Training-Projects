\# TNS Training Projects



This repository contains the projects developed as part of my Technical Training (TNS), showcasing my individual development skills and collaborative project experience.



\## 📚 Projects Overview



\### 1. Individual Project – Intelligent Phishing URL Detector



\*\*Project Type:\*\* Individual Project



\*\*Description:\*\*



An intelligent security application designed to identify and classify potentially malicious URLs using machine learning and URL-based analysis techniques.



\*\*Key Objectives:\*\*

\- Analyze URL characteristics and patterns.

\- Identify potentially malicious or phishing URLs.

\- Classify URLs as legitimate or suspicious.

\- Improve awareness of phishing-related cyber threats.



\*\*Project Folder:\*\* `Individual\_Project/`



\---



\### 2. Group Project – SentinelAI SIEM Platform



\*\*Project Title:\*\* AI-Assisted Security Information and Event Management (SIEM) System



\*\*Project Type:\*\* Group Project



\*\*Description:\*\*



SentinelAI is an AI-assisted security monitoring platform designed to collect and analyze security logs, detect suspicious activities, correlate security alerts and prioritize potential threats.



\*\*Key Features:\*\*

\- Security log collection and processing.

\- Rule-based threat detection.

\- Alert correlation and triage.

\- Threat risk scoring and prioritization.

\- AI-assisted security analysis.

\- Interactive security monitoring dashboard.



\*\*Project Folder:\*\* `Group\_Project/`
